# Trace 4317 性能改造

## 目标
原位优化已安装 Trace extension 与同一 4317 服务；记录、打开会话、点详情均不重复处理全量请求历史。

## 非目标
不新增端口、服务、运行时依赖，不改业务代码、clangd 或宿主守护。原始历史日志保留；静态导出仍由显式 /trace 执行。

## 实现
- shutdown 只 flush，不自动生成 HTML。新增 provider 记录保留请求参数、最后消息与消息数量，不重复序列化全历史和工具 schema；完整对话仍在 Pi 会话文件。
- 4317 持久缓存轻量事件及原始请求字节位置，只读取追加的完整行；历史大 Input 不进入常驻树，点 Input 时只读取对应行。列表复用轻量摘要。
- 树首屏折叠较深层级；JSON 按层展开，长文本先预览；快速切节点时旧请求不得覆盖新选择。

## 验证
增量读取、半截尾行、截断重建、同会话并发、旧 Input 精确读取、摘要兼容；真实 2.6 GB 会话的冷建/热打开/节点点击，并测试前端交互。冷建耗时与热响应分别报告，不把服务器 API 时间冒充用户浏览器时间。
